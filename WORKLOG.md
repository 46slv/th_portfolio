# TH Portfolio Worklog

Last updated: 2026-07-16

## Purpose

This file records implementation notes, current behavior, and debugging context for the TH Portfolio site.

## Current Architecture Notes

- `WorksMap.astro` is the composition layer for the map, filters, audio HUD, and archive wheel.
- Audio logic lives in `src/lib/audio/audioEngine.ts`.
- Filter state lives in `src/lib/filterStore.ts`.
- Work selection state lives in `src/lib/workSelectionStore.ts`.
- Stable DOM IDs for works are generated by `src/lib/workIds.ts`.
- The Archive Wheel UI lives in `src/components/works/ArchiveWheel.astro`.
- Map points are rendered by `src/components/works/WorkNode.astro`.
- A single shared tooltip is rendered by `src/components/works/SharedWorkTooltip.astro`.

## Implemented Changes

### Startup Overlay

- The initial blur state is guaranteed from HTML by adding `body.is-blurred` in `src/pages/index.astro`.
- `StartOverlay.astro` is rendered directly under `body`, outside `#site-shell`, so it remains clickable while the main shell is blurred.
- Startup initialization checks `document.readyState` so it does not depend only on `DOMContentLoaded`.

### Audio

- Audio processing was moved out of `WorksMap.astro` into `audioEngine.ts`.
- Distortion now fully bypasses `WaveShaperNode` when the distortion value is `0`.
- Audio meter uses an `AnalyserNode` instead of random values.
- Playback controls update through the exported audio engine API.

### Filters

- Tag/year filter state was moved to `filterStore.ts`.
- Filtering now only marks unmatched works as `is-inactive`.
- Filtered, matching works are no longer all given `is-active`; this avoids multiple map points looking focused at once.
- `work-filters-applied` is dispatched after filter changes so the Archive Wheel can sync visible entries.

### Archive Wheel

- The wheel is a right-side overlay controlled by `ArchiveWheel.astro`.
- The previous rectangular blur panel was removed.
- Text blur remains on individual wheel items, but the surrounding area no longer applies `backdrop-filter`.
- A circular visual range is rendered to the right of the text using pseudo-elements.
- The wheel can be collapsed to the right edge and reopened with a slim toggle tab.
- While collapsed, `selectedWorkId` is cleared so no map point stays focused.
- Wheel item hover no longer changes selection, which avoids heavy map/wheel synchronization during cursor movement.
- Wheel item click, wheel scroll, drag, and keyboard navigation can still change the selected work.
- Wheel scroll is threshold-based rather than cooldown-based:
  - Scroll delta accumulates.
  - Once the threshold is reached, the wheel moves by one item.
  - Remaining scroll delta is carried forward, making the motion smoother without time-based blocking.

### Map Hover / Focus Performance

- Map point hover no longer calls `setSelectedWork`.
- Selection subscription now caches map nodes once instead of querying all nodes on every selection update.
- Heavy hover styling was reduced:
  - Removed `transition: all`.
  - Removed selected/active `drop-shadow` filters.
  - Reduced scale values.
  - Removed tooltip `backdrop-blur`.
  - Shortened tooltip transition.

### Visual Shift

- The playback speed label was renamed from `Temporal Velocity` to `Relativistic Shift`.
- Visual shift behavior was adjusted toward a redshift-inspired effect:
  - Normal color drift is slower.
  - Higher playback rate increases sepia, hue shift, saturation, brightness, and contrast more strongly.
  - Status text now uses redshift-oriented labels for high rates.

## Current Interaction Rules

- Map hover:
  - Lightweight CSS-only focus.
  - Does not update `selectedWorkId`.
  - Does not rotate or reposition the Archive Wheel.

- Map selected focus:
  - Only one map point should have `is-selected` at a time.
  - Selection is driven by explicit Archive Wheel actions.

- Filtered works:
  - Non-matching works receive `is-inactive`.
  - Matching works remain normal unless explicitly selected.
  - Archive Wheel only shows works that are not `is-inactive`.

- Archive Wheel:
  - Hover does not select.
  - Click selects.
  - Wheel scroll selects by thresholded one-step movement.
  - Drag selects by larger step distance to avoid jitter.
  - Collapse clears selection.

## Performance Stabilization (2026-07-16)

- Restored CSS-only map hover; hover no longer updates `selectedWorkId`.
- Map selection now changes only the previous and next selected nodes.
- Replaced per-work tooltips with one shared tooltip.
- YouTube thumbnail `src` is assigned only when a work is previewed.
- Removed permanent floating animation from every map point.
- Archive Wheel now renders the center item plus four entries on either side.
- Archive Wheel no longer applies per-item blur filters.
- Wheel and drag updates are coalesced through one animation frame.
- Collapsed Wheel selection updates do not trigger a full layout.
- Visual Shift is neutral at playback rate `1.0` and capped at 15fps otherwise.
- Visual Shift and audio meter pause their drawing loops in hidden tabs.
- Audio meter is capped at 24fps and uses `scaleX()` rather than width.
- Reverb impulse creation is deferred until Reverb is first enabled.
- Spreadsheet rows containing only presentation metadata are ignored.
- Startup overlay is a keyboard-operable button.

## Follow-up Ideas
