# Archive rebuild：指示と受入タスク（2026-11-25）

対象は `/archive-rebuild/` のローカル候補。仕様の正本は [Graph-Centered UI](../spec/TH_PORTFOLIO_GRAPH_CENTERED_UI_SPEC.md)。確認単位は下表のとおり。公開、別ルート変更、確認済みプレビューの上書きは含まない。

| タスク | 作業と合格条件 |
|---|---|
| A. 半円からのスクロール開始 | **開いている右端の半円の面全体**を対象にする。何も押さず、文字や軌道に触れた履歴もない状態から、上・中央・下の余白で最初の1回が効く。半円外の矩形の角・閉じた状態は反応しない。画面幅を変えても表示と一致する。 |
| B. 始動・継続・着地の保護 | 小入力の最初の描画と次の描画の間に静止を挟まない。固定カーソルの +8px×12 は12回すべて処理し、二重処理しない。弱い連続入力とノイズを分け、速い操作は減速後に最寄りへ。逆入力、両端、絞り込み、閉じる、確定・取消、Reduced Motion を別々に確認する。 |
| C. 他の操作を奪わない | 作品名への直接タップ、Point・小カード・Detailの同一ID、キーボード、ドラッグ、スワイプ、Tag／Year、音声・画像フォールバックを維持。半円上でも前面のPoint・カード・drawer・リンク・入力・ズームが優先。全画面を捕捉しない。 |
| D. 文字による操作と輪郭のない表示 | `Setting`、`Wheel`、`Tag / Year`、再生、閉じる、リンク、入口を含め、文字の前後に飾り線を付けない。設定・フィルター・作品の小カード／Detail は四角い枠・塗りを使わず、階層は文字と余白で示す。値を伝えるスライダー・音量計・波形・座標軸は残す。選択状態とキー操作時のフォーカスを区別し、当たり判定は縮めない。展開中の作品名のホバーは中央の1件だけ。閉じたホイールには控えめな目盛りのみ戻す。 |
| E. 作品Pointの分布 | 96作品の中心間の広がりを、拡大前比で縦横とも1.7倍以上にするのが目標。座標データ、順序、中心、十字寸法、ヒット範囲を変えない。1098×1249では1.82倍。600×900では端を切らない条件で1.51倍に留まり、達成扱いしない。 |
| F. 照合と引き渡し | 実装と仕様を別作業として並行進行し、同じ候補に統合。旧版と新版を別ポートで照合し、Chromeでの自動入力・タッチエミュレーションと、本人の物理デバイスでの体感確認を区別する。 |
